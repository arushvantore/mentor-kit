# Notes (written by the mentor AI, one file per topic)

Naming: `NN_subject_topic.md` (e.g. `01_dbms_normalization.md`).

Each note = clean revision material for the student:
- Plain words (a 12-year-old could follow)
- Recall-first prompts at the end ("close this note, then: ...")
- Only content that matters for the exam — no padding

These notes are the student's revision layer. The AI reads them before
re-explaining anything (never teach the same topic twice).
